## Data Science Projects 📊

### Otomoto Scraper Bot

Automatically monitors and fetches new vehicle offers from OtoMoto.pl.

🔗 [View repository](https://github.com/Yorick0499/otomoto-bot)

### Auto Sky Logger
Automatically collects weather data from the IMGW API for chosen location and stores it in MongoDB. Runs periodically using GitHub Actions.

🔗 [View repository](https://github.com/Yorick0499/WeatherDB)

### NutriScore Food Classifier

Classifies food products using a custom NutriScore system. An ML model predicts NutriScore labels based on protein, fat, and other nutritional data.

🔗 [View repository](https://github.com/Yorick0499/NutriScore-Food-Classifier)

### NBA Games Predictor

Predicts NBA game outcomes using historical season data with an XGBoost model.

🔗 [View repository](https://github.com/Yorick0499/nba-games-predictor)
